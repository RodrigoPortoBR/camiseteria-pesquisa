# Framework: Análise por Chamada — CazéTV Camiseteria | Copa 2026

> **Princípio:** Toda chamada publicada em qualquer canal é uma unidade de análise independente. O objetivo de toda chamada é, em última instância, gerar acessos qualificados à loja CazéTV no Mercado Livre — seja de forma direta (clique no link) ou indireta (aumentar intenção de compra). A agência deve medir essa influência em todas as 20 origens/mídias mapeadas.

---

## O Que é uma "Chamada"

Uma **chamada** é qualquer peça de conteúdo publicada em um canal que convida o usuário a tomar uma ação — assistir, clicar, comprar, visitar. Exemplos:

| Canal | Exemplos de chamada |
|---|---|
| YouTube Live | Thumbnail + título da transmissão; mensagem fixada no chat com link da loja; QR code exibido na arte da transmissão |
| Instagram | Post de feed anunciando o jogo com link na bio; Story com sticker de link para a loja; Reel de produto |
| TikTok | Vídeo com CTA oral + link na bio; Story com link de swipe-up |
| Twitter / X | Tweet com link + CTA para a loja antes do jogo |
| WhatsApp | Mensagem na Comunidade com link de compra |
| Threads | Post com CTA e link |

Qualquer combinação de **arte + copy + CTA** publicada em um canal é uma chamada analisável.

## O Funil Universal de Conversão

Este funil se aplica a **todas as chamadas em todos os canais**. Os nomes dos indicadores variam por plataforma — os conceitos são os mesmos.

```
┌─────────────────────────────────────────────────────────┐
│                        CHAMADA                          │
│            (arte + copy + CTA publicados)               │
└─────────────────────┬───────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────┐
│  ESTÁGIO 1 — EXPOSIÇÃO                                  │
│  Impressões / Alcance / Visualizações                   │
│  → Quantas pessoas foram expostas à chamada?            │
└─────────────────────┬───────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────┐
│  ESTÁGIO 2 — INTERESSE (CTR)                            │
│  Cliques no link / QR scans / Taps no sticker           │
│  → Quantas pessoas demonstraram interesse suficiente    │
│    para clicar? Qual o CTR da chamada?                  │
└─────────────────────┬───────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────┐
│  ESTÁGIO 3 — ACESSO À LOJA ML                           │
│  Sessões na página da camiseteria no Mercado Livre      │
│  rastreadas via UTM ou QR code com parâmetros           │
│  → Quantos chegaram à loja? (nem todo clique chega —    │
│    taxa de drop entre CTR e sessão é informativa)       │
└─────────────────────┬───────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────┐
│  ESTÁGIO 4 — CONSIDERAÇÃO NA LOJA                       │
│  Visualizações de produto / Add to cart / Favoritos     │
│  → Quem chegou à loja navegou e demonstrou intenção?    │
└─────────────────────┬───────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────┐
│  ESTÁGIO 5 — CONVERSÃO                                  │
│  Pedidos realizados / Receita atribuída à chamada       │
│  → Qual o % de conversão e a receita gerada             │
│    a partir dessa chamada específica?                   │
└─────────────────────────────────────────────────────────┘
```

### Indicadores do Funil por Chamada

| Estágio | Indicador | Descrição |
|---|---|---|
| Exposição | Impressões / Alcance | Pessoas que viram a chamada |
| Interesse | CTR (%) | Cliques / Impressões |
| Interesse | Cliques absolutos | Número total de cliques no link/QR |
| Acesso | Sessões ML (UTM rastreadas) | Visitas à loja vindas desta chamada |
| Acesso | Taxa de drop (CTR → Sessão) | % de cliques que efetivamente chegaram à loja |
| Consideração | Visualizações de produto | Usuários que viram a página do produto |
| Consideração | Add to cart | Usuários que adicionaram ao carrinho |
| Conversão | Pedidos atribuídos | Compras rastreadas à chamada |
| Conversão | Receita atribuída (R$) | Valor dos pedidos com origem na chamada |
| Conversão | Taxa de conversão (%) | Pedidos / Sessões ML |

## Rastreabilidade: UTMs + QR Codes

Para fechar o funil e atribuir acessos à loja ML a cada chamada, **toda chamada precisa de um link rastreável**. Padrão de UTMs recomendado:

```
https://[link-loja-ml]?
  utm_source=[canal]
  &utm_medium=[formato]
  &utm_campaign=copa2026
  &utm_content=[identificador-da-chamada]
```

**Exemplos:**

| Chamada | UTM gerada |
|---|---|
| YouTube Live — Jogo Brasil × Argentina | `utm_source=youtube&utm_medium=live&utm_campaign=copa2026&utm_content=brasil-argentina-jogo52` |
| Instagram Story — Dia do jogo | `utm_source=instagram&utm_medium=story&utm_campaign=copa2026&utm_content=story-gamesday-jogo52` |
| Twitter — Tweet pré-jogo | `utm_source=twitter&utm_medium=tweet&utm_campaign=copa2026&utm_content=tweet-pregame-jogo52` |
| WhatsApp Comunidade — Link de compra | `utm_source=whatsapp&utm_medium=comunidade&utm_campaign=copa2026&utm_content=msg-compra-semana3` |

### QR Codes em Lives (YouTube + TikTok)

QR codes exibidos durante transmissões são a **forma mais direta de rastrear influência da chamada em tempo real**:

- Gerar QR code que aponta para URL com UTM único por jogo
- Exibir o QR code na arte da transmissão em momentos estratégicos (pré-intervalo, gol, encerramento)
- Monitorar GA4 em real-time: cada pico de sessões com aquela UTM = QR code funcionando
- Testar: QR code com URL longa vs. short URL amigável — medir diferença de conversão

### Acessos Orgânicos à Loja (sem link rastreável)

Parte dos acessos à loja ML virão de buscas diretas no próprio Mercado Livre ou de pessoas que viram o QR code mas não escanearam. Recomenda-se:

- Medir o volume de acessos orgânicos à loja ML **antes e durante** os jogos para capturar o uplift não rastreável
- Correlacionar picos de acesso orgânico com horários de publicação de chamadas

## Loop de Otimização por Chamada

```
┌──────────────────────────────────────────┐
│           CHAMADA PUBLICADA              │
└──────────────┬───────────────────────────┘
               │
               ▼
   ┌───────────────────────┐
   │   LEITURA DO FUNIL    │
   │  Exposição → CTR →   │
   │  Sessões ML → Conv.  │
   └───────────┬───────────┘
               │
       ┌───────┴────────┐
       │                │
       ▼                ▼
 Performance        Performance
  ACIMA da          ABAIXO da
   média                média
       │                │
       ▼                ▼
  Documentar        Diagnosticar:
  o padrão         • Arte (thumbnail, imagem)?
  como referência  • Copy (título, legenda, CTA)?
  para próximas    • Formato (link vs QR code)?
  chamadas         • Posicionamento do CTA?
                   • Horário de publicação?
                   • Contexto (jogo do Brasil vs. outro)?
                        │
                        ▼
                   Ajustar próxima
                   chamada e testar
```

### O que investigar quando o funil quebra

| Estágio com queda | Hipótese a investigar |
|---|---|
| Impressões muito baixas | Algoritmo não distribuiu — horário, frequência ou shadow ban? |
| CTR baixo apesar de impressões altas | Arte não atrai clique — thumbnail, título, copy do CTA |
| Sessões ML baixas apesar de CTR alto | Link quebrado, QR code errado, landing page lenta, URL sem UTM |
| Add to cart baixo apesar de sessões | Produto mal posicionado na loja, preço, foto, descrição na ML |
| Conversão baixa apesar de add to cart | Abandono de carrinho — frete, prazo, forma de pagamento |

## Análise Real-Time: YouTube Live + TikTok Live

Durante as transmissões ao vivo, a análise do funil deve acontecer em paralelo à transmissão, com um analista dedicado monitorando:

| Momento | O que monitorar | Onde |
|---|---|---|
| Início da transmissão | CTR da chamada (thumbnail + título) no YouTube Studio | YouTube Studio → Impressões / CTR |
| A cada 15 min | Sessões ML vindas da UTM da live | GA4 → Relatório em tempo real |
| Pico de audiência | Correlação: espectadores × acessos ML | YouTube + GA4 |
| Exibição do QR code | Spike de sessões ML com UTM do QR | GA4 → tempo real |
| Encerramento da live | Consolidado: pico viewers, CTR, total sessões ML, pedidos rastreados | Relatório pós-jogo |

### Hipóteses testáveis em tempo real (live)

- **QR code faz diferença?** Exibir QR code em momentos diferentes da transmissão e medir spike de sessões ML imediatamente
- **Mensagem fixada no chat gera cliques?** Trocar a mensagem fixada durante a live e medir variação de sessões
- **Posição do CTA importa?** Primeira menção do link vs. última menção — medir qual gera mais tráfego
